# デジタル庁デザインシステムには「グラフの色」がない — 検証して作って、AIスキルにした

## AIが作るUIはなぜ「AIっぽい」のか

最近こういう趣旨の記事が回っていた。AI生成UIの「AI感」の正体は、
紫グラデでも絵文字でもなく、**そのプロダクト固有の判断基準が見えないこと**。
だから「いい感じにして」と頼むほど、汎用表現の寄せ集めになって悪化する。

処方箋も示されていた。実在するデザインシステム（デジタル庁、PayPay、LINE、IBM Carbon）の
**判断基準ごと採用し、複数を混ぜない**こと。

納得したので、自作の家計簿アプリ（Streamlit製）で実践してみた。
すると2つ、記事には書かれていない実務の壁にぶつかった。

## 壁①: 公式サイトにHEX値が載っていない

デジタル庁デザインシステム（DADS）のサイトを開くと、カラーパレットのページはあるが
色チップの画像だけで、**HEX値がどこにも書いていない**。「詳細はFigmaを参照」。

答えは npm にあった。

```bash
curl -sL https://unpkg.com/@digital-go-jp/design-tokens@latest/dist/tokens.css
```

MITライセンスで全プリミティブが取れる。ここから分かることは意外に多くて、

- フォントウェイトは **400 と 700 しか存在しない**（500を使ったら準拠ではない）
- 補助テキストに使える最も薄いグレーは `#767676`（白地で4.5:1を満たす下限）
- 角丸は 4 / 8 / 12 / 16 / 24 / 32px の段階のみ

「体系に**無い**もの」を知ることが、混ぜないための第一歩だった。

## 壁②: データ可視化のパレットが存在しない

DADSは行政サービスのUI向け体系なので、**グラフ用のカテゴリカルパレットが無い**。
ダッシュボードを作るなら自分で選ぶしかない。

素朴にプリミティブから青・橙・緑・黄土を選んだら、
色覚シミュレーションの検証で落ちた。**緑と黄土は、色覚特性のある人には
ほぼ同じ色に見える**（OKLab ΔE 6.6、基準は8以上）。

緑をCyan-600に差し替えて再検証し、ΔE 19.5・全色コントラスト3:1以上で合格：

```
light（白地）:  #3460FB  #E25100  #00A3BF  #B78F00
dark（#1a1a1a）: #4979F5  #E25100  #00A3BF  #B78F00
```

見た目の好みではなく計測で決める。ここまでやって初めて「体系に乗った」と言える。

## で、この知見は再利用できないと意味がない

調べた値と判断を、**AIエージェントがそのまま従える形式（スキル）**にまとめて公開した。

**https://github.com/T-Yamada7/ui-skills**

```
skills/dads/               実測トークン全部＋検証済みチャート4色
skills/extract-ui-system/  新しいシステムを自分で抽出する手順書
```

Claude Code ならプラグインで入る：

```
/plugin marketplace add T-Yamada7/ui-skills
```

中身は素のMarkdownなので、Cursorの rules に貼っても、
プロンプトに貼っても機能する。使うときはこう頼むだけ：

> dadsスキルに従って設定画面を作って

## 抽出の方法論（ここが本体）

`extract-ui-system` スキルに焼き込んだ原則：

1. **実測値だけを書く**。目視で推測したHEXは書かない。出所・版・取得日・確度を明記
2. **1スキル＝1システム。混ぜない**
3. **チャート色はバリデータ（CVD・コントラスト）を通した値だけ**。検証数値も残す
4. **「体系に無いもの」も書く**
5. **ライセンスを確認してから公開する**。実は PayPay も公式npmから抽出したのだが、
   パッケージにライセンス記載が無かったため公開リポジトリには入れていない。
   手元で `extract-ui-system` を走らせれば同じものが作れる

自動抽出ツール（SkillUI等）は「何でも・速く」やってくれる。
このリポジトリは逆に「少数を・検証して・判断記録ごと」残す。
AIに渡す判断基準は、量より確度だと思う。

## まとめ

- 「AI感」の正体は判断基準の不在。デザインシステムを**丸ごと**採用するのが処方箋
- ただし実務では「HEXが公開されていない」「グラフ色が無い」の2つの壁がある
- 埋めた結果をスキルとして公開したので、同じ壁の前にいる人はどうぞ
