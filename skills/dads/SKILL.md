# デジタル庁デザインシステム（DADS）

出所: `@digital-go-jp/design-tokens@1.1.0`（npm, 取得日 2026-09-27、**確度: 実測**）
原本: 同フォルダの `tokens-simple.css`（全プリミティブ色）

## 使い方

このスキルを読んだら、以下の値を**そのまま**使う。他のシステムと混ぜない。
「いい感じに」アレンジした時点で DADS 準拠ではなくなる。

## 書体

| 項目 | 値 |
|---|---|
| 本文・見出し | Noto Sans JP |
| 等幅（金額・コード） | Noto Sans Mono |
| ウェイト | **400 と 700 のみ**（500・600 は体系に存在しない） |
| 基準サイズ | 16px |
| 行間 | 1.2〜1.7 の段階（本文 1.7、見出し 1.2〜1.4） |

Google Fonts:
`https://fonts.googleapis.com/css2?family=Noto+Sans+JP:wght@400;700&family=Noto+Sans+Mono:wght@400;700&display=swap`

- 420 は白地に対し 3:1 を満たす最小（アイコン・罫線の下限）

error = Red-800 `#ec0000`（強調 900 `#ce0000`）/
warning = Yellow-700 `#b78f00` または Orange-600 `#fb5b01`

面: 背景 `#ffffff`・薄い面 `#f2f2f2`・罫線 `#cccccc`
ダーク面: 背景 `#1a1a1a`・薄い面 `#333333`・罫線 `#4d4d4d`

## チャート4色（DADSに可視化パレットは無いため、プリミティブから選定し検証済み）

| モード | 面 | 4色 | 検証結果 |
|---|---|---|---|
| light | `#ffffff` | `#3460FB` `#E25100` `#00A3BF` `#B78F00` | CVD最悪 ΔE 19.5 / 通常視 22.7 / 全色 3:1 以上 |
| dark | `#1a1a1a` | `#4979F5` `#E25100` `#00A3BF` `#B78F00` | 同上 |

（Blue-600/500・Orange-700・Cyan-600・Yellow-700。
Green は Yellow との CVD 分離が ΔE 6.6 で不合格だったため Cyan に差し替えた。
再検証: dataviz スキルの `validate_palette.js` にこの4色と面色を渡す）

順次スケール（単色濃淡）: Blue 50→900 を使う。

## 文言のトーン

- 敬体。ただし指示の連発を避け、事実と選択肢を提示する
- **UIに絵文字を使わない**
- ボタンは動詞（「保存」「送信」）。「〜する！」のような煽りは使わない

## この体系に無いもの（使ったら準拠ではない）

- フォントウェイト 500・600
- 紫系のアクセント（Purple はプリミティブにあるがキーカラーではない）
- グラデーション
- データ可視化パレット（上の4色はこのスキル独自の検証済み拡張）
